# UI 与交互分任务书

> 负责 Windows 客户端的视觉、信息架构、交互、可访问性和页面性能。设计约束见 [`../reference/UI设计规范.md`](../reference/UI设计规范.md)。

## 已交付基线

- 柔和 Surface、统一圆角/间距、主题化 SVG 图标和亮暗主题。
- 题库、笔记、复习、录题、设置及首批低频窗口的页面迁移。
- 主侧栏、窄窗口策略、阅读画布、工作流步骤条和非阻塞 Toast。
- 主导航快捷键、搜索快捷键、核心表单 Tab 顺序和字段级可访问名称。
- 题库富文本行按视口实例化；1200 题/300 笔记隔离性能验收。

## P0 · 发布前收口

### UI-001 · 详情与数据结果可访问性

- 状态：就绪
- 来源问题：历史 UI 任务收口
- 范围：题目详情、导入导出结果、云端恢复/合并与同步结果。
- 实施要求：检查 Tab 顺序、焦点可见性、快捷键提示、读屏名称和错误恢复入口。
- 验收：QTest 覆盖核心焦点链；真实 Windows UI Automation 至少抽查一个详情页和一个结果窗口。

### UI-002 · 低风险信息提示审计

- 状态：就绪
- 范围：剩余 `QMessageBox.information`。
- 实施要求：短小、可恢复、不要求记住路径或明细的成功反馈可迁移为 Toast；路径、合并明细、异步任务完成和高风险结果必须保留可停留对话框。
- 验收：列出保留与迁移清单；迁移场景有回归测试。

### UI-003 · 局部样式与状态收口

- 状态：就绪
- 范围：旧的页面局部硬编码样式、重复原生按钮组合，以及缺失的加载、失败、禁用和权限不足状态。
- 验收：不得新增业务行为变化；新增状态有单元测试和亮暗主题检查。

## P1 · 明确体验缺口

### UI-101 · 题库卡片视图决策

- 状态：待澄清
- 问题：当前题库以高效列表为主，旧目标仍写有“列表/卡片切换”，但没有明确使用价值。
- 需要决定：实现独立卡片视图，或正式删除该目标并保持单列表方案。

### UI-102 · 笔记批量管理

- 状态：就绪
- 范围：批量移动合集、归档或移入回收站。
- 边界：不把单篇编辑器直接复制成满屏批量工具栏；批量操作只在多选后渐进披露。

### UI-103 · 复习计划详情与历史

- 状态：就绪
- 范围：计划内容预览和历史入口。
- 已完成：构建器列表/卡片切换、草稿计数、拖动顺序、重复加入保护和窄窗口专注视图。

### UI-104 · 复习会话键盘提示

- 状态：就绪
- 范围：统一题目与笔记复习会话的键盘提示展示。
- 边界：保留现有阅读画布、答案披露和评分流程。
