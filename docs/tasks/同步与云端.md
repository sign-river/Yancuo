# 同步与云端分任务书

> 负责完整快照、增量 Operation、远端提供商和跨资料恢复/合并。协议以 [`../../protocol/README.md`](../../protocol/README.md) 为准。

## 已交付基线

- `.ebpack` 完整快照、资料发现、恢复、接管和字段级显式合并。
- LocalFolder Operation 增量通道。
- GitHub 不可变 JSONL 批次、Release 写锁、附件校验、幂等拉取和私有仓库真实联调。
- GitLink 完整快照。
- 云端连接成功后保存提供商、仓库 owner/name 和本地云目录；令牌只进入系统凭据管理器。

## 当前任务

### SYNC-101 · GitLink 原子锁能力

- 状态：阻塞
- 已验证：`version_id` 是资源标识，不是条件版本；旧版本写入可以覆盖新版本。
- 启动条件：GitLink 提供可复现、可自动化验证的条件更新、原子锁或等价机制。
- 验收：两客户端并发竞争时只有一个写入者成功，旧版本不能覆盖新版本，锁不能误释放他人所有权。
- 边界：条件未满足前不得实现或隐藏开放 GitLink Operation 增量通道。

### SYNC-102 · 正式通道回归矩阵

- 状态：已交付
- 范围：LocalFolder、GitHub 和完整快照的发布失败、重复拉取、附件篡改、跨资料隔离及恢复回滚。
- 验收：`python tools/sync_release_matrix.py` 为可重复执行的发布前入口，不依赖真实用户资料。

## 后置

- 账号服务器、协作共享题库和实时同步不在当前范围。
- 任何新远端通道必须先定义锁、不可变批次、索引提交点和恢复语义。
