# 研错库数据库版本历史

> 当前 Windows `schema_version=19`，跨端 `data_format_version=1`。本文合并原先分散的 schema 变更说明；迁移实现以 `apps/windows/src/yancuo_win/data/migrate.py` 为准。

## 兼容原则

- 所有现有迁移均为加法迁移，不删除或重命名既有业务字段。
- 高版本数据库不能由只支持低版本的客户端打开。
- v7 之后，旧库升级前创建并校验 SQLite 在线备份；迁移失败时关闭连接池并原子恢复。
- 空库不创建无意义的升级备份。
- 搜索投影和 FTS 是可重建数据，不能反向覆盖题目或笔记权威表。
- 完整 `.ebpack` 快照携带数据库表，但 Windows 专用流程表不等于 Android UI 能力承诺。

## 关键生命周期

### 题目录入（v6、v13、v14）

```text
IntakeSession
  → IntakeAsset / RecognitionUnit
  → AiJobItem
  → IntakeCandidate
  → 用户确认
  → Problem 或 ProblemSet + 子题
```

- 来源图使用内容寻址存储，可被录题会话、正式题目和笔记安全共享。
- 删除错误候选不会制造回收站题目。
- 多图识别单元只描述 AI 输入，不自动等同于复合题。
- 复合题共享材料只保存一次，子题保持独立复习和搜索。

### 笔记录入（v8—v10）

```text
NoteIntakeSession
  → NoteIntakeAsset
  → NoteDraftGroup / NoteDraftBlock
  → 用户确认
  → NoteDocument / NoteBlock / NoteAsset
```

- 草稿状态支持 `draft → processing → review → completed`，失败可重试，放弃进入 `cancelled`。
- 已有分类使用稳定 ID；新分类只保存提案，用户确认前不创建目录。
- 笔记可以属于多个合集，知识分类与个人合集互不替代。

### 搜索（v7、v11）

- 3 个及以上字符使用 FTS5 trigram；1—2 个字符使用本地 `LIKE` 回退。
- 搜索投影与权威写入共享事务，并在启动时诊断修复。
- AI 搜索只能处理本地受限候选和固定 JSON Schema，不能生成 SQL 或扩大本地边界。
- Windows 恢复快照时可从普通投影重建平台本地 FTS 虚表。

## 时间与复习

- 数据库时间使用 UTC。
- 复习日期按照 `Asia/Shanghai` 本地日历计算。
- v16 之前的题目继续保持原有进入复习队列的行为，但不会伪造详细学习记录。
- v19 笔记复习只记录完成，不创建题目评分和间隔。
