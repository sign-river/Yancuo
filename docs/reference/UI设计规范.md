# 研错库 UI 设计规范

> 本文只维护稳定的视觉和交互规则。未完成任务见 [`../tasks/UI与交互.md`](../tasks/UI与交互.md)，历次试验和性能数据见 Git 历史与 [`../完成记录.md`](../完成记录.md)。

## 设计目标

界面应当自然、柔和、清晰，接近现代办公软件的克制感，而不是由大量 Qt 原生矩形控件拼接而成。柔和不等于低对比或过度圆润，核心是稳定层级、低噪声边界和渐进披露。

关键词：

- 本地优先、可信、安静；
- 柔和表面、低饱和选择态；
- 信息架构先于装饰；
- 主动作明确，次要动作克制；
- 键盘、读屏和窄窗口属于基础质量。

## 视觉层级

1. 应用背景：承接整体空间，不直接放复杂业务控件。
2. 页面工作区：一个主要外壳，使用统一圆角和内边距。
3. 主/次表面：通过背景差和留白分组，避免连续深色竖线。
4. 浮层：对话框、菜单和 Toast，允许比普通表面更明显的边界。

页面不应同时出现多个高饱和主按钮；只有当前流程最重要的动作使用主色。

## 尺寸与曲率

- 控件圆角：约 8px；
- 行项目圆角：约 10px；
- 工作区圆角：约 14px；
- 浮层圆角：约 16px；
- 控件高度保持 36—40px 的稳定档位；
- 行高根据内容使用 40px、48px 或 56px，不为“显得宽松”任意增高；
- 分栏沟槽使用透明留白，不使用粗硬分割线。

具体数值集中在 `ThemeTokens` 和 `UiMetrics`，页面不得重复硬编码颜色、圆角和随机间距。

## 公共组件

- `PageHeader`：页面标题、说明、返回入口和主要动作。
- `SearchInput`：统一搜索图标、清除动作、焦点和可访问名称。
- `IconButton`：仅使用主题感知 SVG 图标，并提供 Tooltip。
- `StatusTag`：表达状态，不代替按钮。
- `SoftItemDelegate`：列表/树的内缩圆角 hover、selected 和 focus。
- `ReadingCanvas`：长正文居中并限制最大阅读宽度。
- `WorkflowStepBar`：连续流程的位置提示，不作为可点击导航冒充分页。
- `ToastMessage`：短小、可恢复且不要求记住路径或明细的反馈。
- `ConfirmDialog`：危险、不可逆或需要明确复核的动作。
- `LoadingSkeleton`、`EmptyState`、`ErrorState`：分别承接加载、空和失败状态。

## 页面模板

### 浏览管理页

适用于题库和笔记：

- 左侧目录或空间；
- 中间列表；
- 右侧详情或阅读；
- 搜索和批量操作位于内容顶部；
- 窄窗口先保留列表与正文，目录按需披露。

### 连续工作流

适用于 AI 录题：

- 明确显示上传、处理、确认三个阶段；
- 处理状态与业务表单分离；
- 确认阶段允许回看来源并纠偏；
- 主要提交动作集中在底部操作栏；
- AI 建议不会静默创建正式分类或题目。

### 阅读与复习

- 正文进入受限宽度阅读画布；
- 答案披露后才能评分；
- 进度、返回、评分和次要动作保持固定层级；
- 键盘提示应在需要时可见，不依赖用户猜测。

### 设置与数据

- 按账户、AI、外观、本地数据和云端同步分组；
- 普通保存使用轻量反馈；
- 密钥和令牌不显示完整值，不写入明文配置；
- 导出路径、恢复结果和合并明细使用可停留对话框。

## 交互反馈

使用 Toast：

- 设置已保存；
- 已加入复习；
- 已撤销或完成简单归类；
- 索引重建已触发或完成且无明细需要阅读。

保留对话框：

- 删除和覆盖确认；
- 导入导出路径；
- 同步、恢复与合并明细；
- 冲突、失败恢复和异步任务最终结果；
- 需要用户复制、记住或作出后续选择的信息。

## 可访问性

- 所有可操作控件必须有可访问名称；复杂字段增加说明。
- 表单使用显式 Tab 顺序，跨容器顺序在控件挂载后设置。
- 列表、树和选中项需要主题化焦点环。
- 主导航提供 `Ctrl+1`—`Ctrl+4`、`Ctrl+,`；题库和笔记使用 `Ctrl+K` 聚焦搜索。
- 不以颜色作为唯一状态信息；禁用、错误和进行中状态必须可朗读。

## 响应式与性能

- 主窗口最低支持约 `760×560`；小于 900px 自动隐藏侧栏。
- 笔记窄窗口默认保留列表与正文；计划构建器窄窗口使用同页专注草稿视图。
- 纯文本长列表优先使用固定行高和批量暂停重绘。
- QWidget 富内容列表只有在真实采样证明为瓶颈时采用按视口实例化。
- 原图预览缩放属于业务映射，不因视觉重构擅自修改。

## 页面验收

每个页面改造至少检查：

1. 浅色和深色；
2. 1366×768、1920×1080 和窄窗口；
3. 空、少量和长列表；
4. hover、selected、focus、disabled；
5. Tab 顺序和可访问名称；
6. 对应单元测试；
7. Ruff、Python 编译和完整回归。
