# schema v10 变更说明

## 背景

个人复盘、考试计划和学习主题不属于稳定的科目/章节树，也不能由普通标签替代。schema v10 新增独立合集，允许同一笔记加入多个合集且不改变其知识分类。

## 迁移

| 项目 | 变更 |
| --- | --- |
| `schema_version` | **9 → 10** |
| `note_collections` | 新增个人合集：标题、说明、稳定排序与时间戳 |
| `note_collection_documents` | 新增合集与笔记多对多成员关系，以及合集内成员排序 |
| `data_format_version` | 保持 **1** |

迁移为纯加法。删除合集只删除成员关系，绝不删除 `NoteDocument`、内容块、标签、原图或知识目录。笔记仍可独立存在，也可同时属于多个合集。

## 兼容性

Windows v9 旧库升级前沿用在线备份、完整性检查和失败原子恢复。`.ebpack format_version=1` 不变；完整快照会自然携带 v10 表。Android 导入器校验并保留 v10 快照，但 Android UI 仍不读写笔记和合集。
