## 近期交付

### 2026-07-29 · AI 考研章节识别确认闭环

- AI 录题必须依据科目通用考试大纲判断章节，优先匹配本地完整章节路径。
- 本地缺少目标章节时，确认页显示规范章节建议、理由与置信度；用户接受后才创建，也可改选现有章节或保留未指定。
- 修复已有科目下的新章节提案在确认入库时被忽略的问题。
- 题库不再显示 0 题的“未分类”虚拟节点；存在未指定章节题目时改用带说明的筛选入口，归类完成后自动消失。

### 2026-07-25 · GitHub Operation 批次

- 定义不可变 JSONL 批次 Release 协议，索引仅在附件哈希校验成功后更新。
- GitHub 以专用 Release 标签实现保守写锁；竞争设备不能窃取或释放他人锁。
- `SyncService` 支持 GitHub 批次发布、下载、资料隔离和既有字段级冲突合并。
- 离线回归覆盖发布失败、重复拉取、附件篡改、损坏索引和跨资料隔离。
- 私有测试仓库真实联调通过：锁竞争、附件上传下载及哈希核对、发布中断恢复、两端批次推拉与同字段冲突审核。
- GitHub API 对 TLS 瞬态断连执行有限退避重试；GitLink 增量通道仍未完成。

### 2026-07-26 · GitLink 原子锁验证

- 在专用私有仓库中让两个客户端使用相同旧 `version_id` 顺序更新同一 Release；第二次旧版本写入被接受并覆盖第一次结果。
- 结论：`version_id` 是资源标识而非条件版本号，GitLink 不具备可复现的原子锁语义；增量 Operation 通道保持禁用，仅支持完整快照。

### 2026-07-25 · 本地资料接管与显式合并

- 资料快照携带稳定 `profile_id` 与谱系；可发现、恢复和绑定指定云端资料。
- 两份非空资料可逐字段选择本地/云端值，选择主资料后写入别名。
- 合并前创建不可变快照，合并结果不自动上传；搜索投影随后重建。
