## 当前进度

路线图 A–K 的代码与协议验收范围已落地，当前 Windows 数据库为 `schema_version=17`，跨端字段语义为 `data_format_version=1`。这里的“完成”指对应阶段的实现已入库，不等于所有后续能力（加密、PDF、远端增量同步）都已提供。

主线后已落地：

- AI 密钥可在设置写入系统凭据（环境变量优先）
- Faro API 已作为默认真实识图提供商：支持连接测试、图片多模态请求，以及提供商/模型跨重启保存；Mock 仅保留为离线测试选项
- Windows 主界面现代化（侧栏分页 + 统一主题）；设置可跟随系统或固定浅色/深色，Qt 控件与公式阅读页即时同步换肤
- 任务式录题第一阶段：新增工作台与独立录题模块，手动/AI 上传、处理、确认和入库在同一页面栈内连续完成
- 录题阻断修复：上传后即时大图/缩略图预览；回收站图片可重新录入；永久删除会安全清理 AI/审核关联和无引用原图
- 公式阅读与题目详情：AI 确认、题目详情和今日复习统一离线渲染 LaTeX；题库可双击或点击按钮进入主内容区详情页
- AI 网络韧性与复习闭环：Faro 临时断连自动退避重试且失败项可原任务续跑；今日复习已迁入主内容区，评分后连续切题
- 详情操作闭环：支持前后题、加入今日复习、收藏、归档、删除、回收站恢复和原图缩放，并保留题库/复习返回来源
- 题库局部刷新：单题录入、编辑、复习与状态操作不再清空整张列表；必要的全量刷新会恢复筛选、选中项和滚动位置
- AI 一图多题：兼容旧单题 JSON 与新的 `problems` 数组，同图候选逐题确认、独立入库并共享内容寻址原图
- AI 候选区域与人工纠偏：确认页高亮当前题目范围，可拖拽重画、框内移动、通过四边四角控制柄微调、恢复整图、拆分或合并
- 专用录题暂存：新 AI 录题在确认前不创建 `Problem/inbox`；手动表单与原图自动保存，可在关闭程序后继续
- 录题会话状态治理：主页只显示真实待处理批次，区分处理/确认/失败状态，支持继续或放弃且不影响已入库题目
- 录题与复习操作层级：AI 录题为推荐主入口，完成页可返回录题主页；复习必须先显示答案与解析才能评分
- AI 性能诊断：处理页展示真实阶段与单图分阶段耗时，审计失败阶段和自动重试；候选蓝框明确为原图来源区域
- 真实 Faro 性能基线：180KB 单图的真实请求端到端约 27.25 秒，其中本地编码约 5ms、远端请求约 27.25 秒；Provider 未返回 token 明细，后续取舍仍以更多样本为准
- 识图结果复用：同一原图、提示词、模型与字段约束完全一致时复用已成功的本地结构化结果；进度页明确显示缓存命中，损坏或不完整缓存自动回退真实识别
- 图片分组识别：上传页可显式选择自动、一图一题、一图多题或多图一题；多图一题按上传顺序在单次视觉请求中发送，识别单元与候选完整保留全部原图来源（schema v13）
- 复合题基础模型：`ProblemSet` 共享材料与来源图只保存一次；子题保持独立题目、答案、解析、搜索和复习记录（schema v14）
- 自动结构建议：自动识别会显示题目结构、子题数、置信度、依据与信号；建议只供用户判断，绝不静默改组图片或创建题组
- 确认页分组控制：可调整多图来源顺序、拆分为单图识别单元；普通确认按独立题入库，也可显式将当前待确认候选作为共享材料题组入库
- AI 分类安全：现有目录以稳定 ID 受控匹配；无合适目录时可提出带理由的新分类，只有用户确认时才会创建，且会拒绝无效父级、近义名称和别名冲突
- 离线账户资料：账户页展示本地身份、设备、数据目录及 AI/云服务连接状态；在线账号尚未配置，不会阻断本地使用
- 云备份决策：不建设账号服务器；用户使用自己的 GitHub/GitLink 私有仓库，按随机资料 ID 创建不可变 `.ebpack` Release 快照，跨设备恢复或合并必须显式确认
- 云端资料基础：本地 `profile_id` 已写入快照与 Release 谱系；可发现并恢复指定云端资料到新目录，非空资料合并仍需后续确认流程
- 候选区域重新识别：蓝框生成临时裁切副本，新旧 AI 结果对比后再明确采用；支持撤回且不修改原图
- 题库章节树基础：递归知识路径、父节点后代题数聚合与包含后代筛选已进入应用服务；目录维护具备跨科目、循环和删除保护，模板按完整路径保留同名分支
- 题库双视角：正式题目按“浏览题库”组织，待整理、归档和回收站集中到“处理中心”；两边分别记忆筛选位置
- 可展开知识树：科目和任意深度章节显示聚合题数，父节点包含全部后代；支持未分类筛选、完整路径面包屑和展开状态保持
- 目录维护与分类移动：知识树可新增、重命名、移动、排序和安全删除目录；题目支持单题/批量移动，AI 只使用有效完整路径
- 题库智能视图与范围：增加收藏、最近 30 天入库；科目、未分类和章节子树统一为可供普通/AI 搜索复用的稳定范围
- 本地搜索基础：schema v7 增加可重建 `SearchDocument` 投影和 FTS5 trigram 索引，支持中文、标签、状态及知识范围离线检索；旧库升级前自动备份，失败会原子恢复
- 搜索索引实时一致：题目、标签、状态、分类、导入与同步写入在同一数据库事务内维护投影；启动自动诊断修复，设置页可手动检查和重建
- 题库离线搜索界面：普通搜索支持题目、答案、解析、标签、备注和来源，可在当前知识范围与全部正式题目间切换；处理中心保持状态隔离，AI 搜索入口在安全规范完成前明确禁用
- AI 搜索安全规范：模型只能返回固定 JSON Schema 的白名单 `SearchSpec`；状态和知识范围由本地程序强制注入，SQL、未知字段、越权范围和超限结果会被拒绝
- AI 搜索已接入题库：网络请求在后台线程执行，界面显示当前阶段、候选范围、披露字段、耗时、token 和估算费用；失败时保留查询并可回退普通搜索
- 笔记基础模型：schema v8 新增独立的 NoteDocument / NoteBlock / NoteAsset 与笔记标签关系；笔记不复用题目字段，统一搜索仍待接入
- 笔记本地编辑与阅读：侧栏可按生命周期浏览、创建和编辑标题/文本/概念/公式/提示块；阅读页统一离线渲染公式，显示来源区域，并按需打开带蓝框标注的原图
- AI 笔记录入与分类模式：录入前可选择 AI 识别并分组或自定义分类；草稿分类行可展开编辑、选择已有路径或保存新分类提案，并可安全新增、删除空组或合并分组
- 概念块整理：草稿确认页支持列表与紧凑网格；可拖拽或右键跨组移动，也可直接编辑组内序号，短概念自动紧凑排布、长内容保持可读
- 可恢复笔记分类暂存：schema v9 独立保存会话、不可变来源图、分类组和草稿块；中断后可用同一会话重试，确认前不创建正式笔记
- 可发布基线第一轮：正式题目写操作补齐 Operation 日志与远端 create 落地；ZIP/`.ebpack`/`.gmshare` 恢复增加路径、体积、校验与回滚保护
- Windows wheel 已内置默认配置与协议 schema，并新增 Python 3.11–3.13 的 Windows CI、静态检查和安装后资源烟测

**详细条目与强制登记约定见 [`docs/08_完成更新记录.md`](docs/08_完成更新记录.md)。** 每完成一次可交付更新，必须先追加该文档，再刷新本段摘要。

当前边界与后续：

- 图片识别目前以每张图独立请求为主；自动/一图一题/一图多题/多图一题、复合题共享材料与独立子题已进入任务规划，尚未实现。
- 题目 AI 当前已收到现有分类路径并优先匹配已有目录；后续将升级为稳定分类 ID、近义去重，以及“无合适目录时由 AI 生成新分类并随入库确认创建”，笔记分类也复用同一规则。
- 笔记分类确认已具备可恢复会话、识别前模式选择、分类行编辑、概念块多布局整理和按组独立入库；统一搜索支持离线检索标题、内容块、标签和合集，AI 仅重排本地候选。
- 搜索架构决策：当前保持 FTS5 trigram 与受限 AI 重排，不引入 embeddings、向量数据库或额外远端文本披露；待 Provider 能力与真实规模基准变化后再评估。
- `.ebpack` v1 当前仅支持未加密包；`protocol/encryption-v1.md` 仍是设计占位。
- Word 是当前稳定导出路径，PDF 导出尚未纳入可用能力承诺。
- Android 可校验并导入当前未加密 Windows schema v9 `.ebpack` 快照，但不提供笔记/草稿 UI，也尚未实现 GitLink/GitHub 云下载或增量同步。
- GitLink/GitHub 当前以完整 Release 快照为主；LocalFolder 才提供已接入的 `changes/` Operation 通道。
- 插件、本地模型等仍属于可选后续方向。

协议入口：[`protocol/README.md`](protocol/README.md)；分享包规范：`protocol/gmshare-format-v1.md`；最新 schema 变更：[`docs/15_schema_v9_变更说明.md`](docs/15_schema_v9_变更说明.md)。

## 快速开始（Windows）

```powershell
cd apps/windows
pip install -e ".[dev]"
python -m yancuo_win
```

首次使用真实 AI：打开“设置”，粘贴 Faro Key 并保存，填写模型广场中支持图片输入的模型 ID，依次点击“测试 Faro 连接”和“保存并应用 AI 设置”。密钥只保存在 Windows 凭据管理器；也可在启动前设置临时环境变量 `FARO_API_KEY`。

测试：

```powershell
cd apps/windows
pytest ../../tests -q
```

源码 checkout 运行时数据目录默认：`apps/windows/.yancuo_data/`；wheel 安装后默认使用当前用户数据目录。两者均可用 `YANCUO_DATA_ROOT` 覆盖。

## 原则摘要

- API 密钥不得明文入仓；配置只用环境变量/凭据引用名
- 第一阶段只做本地稳定功能，不提前做复杂多端同步
- 修改架构或数据格式前先说明兼容性影响
